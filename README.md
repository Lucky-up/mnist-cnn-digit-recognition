# 基于CNN的手写数字识别系统（MNIST）
这是一个基于 **PyTorch CNN卷积神经网络** 实现的手写数字识别完整项目，包含：模型训练、准确率可视化、GUI手绘实时识别功能。
模型测试集准确率稳定 **99%+**，适合深度学习课程作业、入门Demo展示。

## ✨ 项目特色
- 采用**增强三层卷积神经网络**，精度高、泛化能力强
- 支持**本地鼠标手写数字实时识别**（独立GUI界面，无需联网）
- 专属手写优化：自动去白边、居中、高斯模糊、尺寸归一化，大幅提升手写识别准确率
- 全自动流程：数据集下载 → 训练 → 评估 → 保存模型 → 可视化曲线
- 代码结构清晰、无冗余，可直接用于课程作业提交

## 🧠 网络结构（增强版CNN）
针对手写识别优化的三层卷积网络，搭配正则化防止过拟合：
1. 卷积层1：1通道 → 32通道，3×3卷积 + ReLU激活 + 最大池化
2. 卷积层2：32通道 → 64通道，3×3卷积 + ReLU激活 + 最大池化
3. 卷积层3：64通道 → 128通道，3×3卷积 + ReLU激活 + 最大池化 + Dropout
4. 全连接层：1152 → 256 → 10（10分类对应数字0-9）
- 优化器：Adam
- 损失函数：交叉熵损失

## 🎯 手写识别优化方案
解决原生模型手写识别准确率低的问题：
- 自动裁剪画布多余白边，提取有效数字区域
- 数字自动居中归一化，匹配标准MNIST样本
- 高斯模糊柔化鼠标硬边，贴合真实手写风格
- 灰度、尺寸、归一化参数完全对齐训练数据集

## 📌 手写识别使用技巧
1. 仅书写**单个数字**，禁止连笔、反复描线、多数字书写
2. 数字居中绘制，大小适中，不要过小或贴近画布边缘
3. 尽量书写标准印刷体数字，避免潦草、艺术字体
